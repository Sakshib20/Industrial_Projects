# ⚙️ Industrial Engineering Projects

## 📌 Repository Overview
This repository contains a collection of complex, industrial-grade projects developed during my intensive technical training. These applications focus on low-level system architecture, core networking, and secure data handling using **Java** and **Python**.

## 📂 Project Directory

### 1. [MD5-Secured Backup Automation Tool](./MD5-Secured_Backup_Automation_Tool)
An automated, Python-based periodic background surveillance and backup system. 
* **Tech Stack:** Python, `hashlib`, `shutil`, `schedule`.
* **Core Logic:** Implements a smart incremental backup algorithm using **MD5 cryptographic checksums** to verify file integrity and seamlessly copy only newly modified data into timestamped archives.

### 2. [Secure File Packer-Unpacker Utility](./File-Packer-Unpacker-With-Encryption)
A custom CUI-based archiving tool designed for secure data storage and integrity validation.
* **Tech Stack:** Java, File I/O, Byte-level manipulation.
* **Core Logic:** Combines multiple files into a single encrypted archive. Implements **Magic Number validation** and header parsing to securely extract files without data corruption or loss of original metadata.

### 3. [Synchronous Client-Server Chat Application](./Client-Server-Chat-System)
A real-time, CUI-based communication system built from scratch without external frameworks.
* **Tech Stack:** Java, TCP/IP Socket Programming, Multithreading.
* **Core Logic:** Implements synchronous bidirectional messaging between clients and a central server, ensuring stable, low-latency packet delivery over a local network.
